# Machine learning capstone projects

Four studies on crop imagery, audio, and housing data. Each project includes Python scripts, setup instructions, and results from its evaluation.

| Project | Main result |
| --- | --- |
| [Crop disease detection in Ghana](projects/ghana_crop_disease/) | Tiling increased correctly labeled small-box recall from 2.8% to 15.5%. Overall average precision stayed below 1%. |
| [Voice commands in noisy environments](projects/noisy_voice_commands/) | Mixing both audio conditions in training increased very-noisy accuracy from 96.0% to 97.9%. |
| [Major and minor chord recognition](projects/major_minor_chords/) | Triad-fit features reached 94.0% accuracy on held-out recording families. |
| [Melbourne house price prediction](projects/melbourne_house_prices/) | Gradient boosting reduced mean absolute error from A$300,731 to A$148,517 on later sales. |

Open a project’s README for its dataset requirements and commands. The chord predictor can also run on a single isolated chord WAV.
